# LGADNet: LAMOST DR12 CEMP Candidate Search

This repository provides code to estimate stellar parameters from LAMOST DR12 spectra, select candidate carbon-enhanced metal-poor (CEMP) stars, and generate the associated figures. The workflow consists of training, prediction and crossmatching, screening, and plotting.

The final release catalog is `catalog/mp_catalog.csv`. Its parent sample comprises all predictions classified as metal-poor, including both CEMP and non-CEMP stars. The catalog records the VMP/CEMP classifications and the outcomes of the CEMP screening chain.

## 1. Configure the data root

Scripts that use default data paths share the `LGADNET_ROOT` environment variable. Set it once in your terminal; there is no need to edit the individual scripts:

```bash
export LGADNET_ROOT="/path/to/lgadnet_data"  # replace with your data-root path
```

Run the commands below from the repository root in the same terminal session where `LGADNET_ROOT` is set. Organize the input data and generated outputs as follows:

```
lgadnet_data/                                  # LGADNET_ROOT
├── dr12/                                      # User-provided input data
│   ├── lamost_dr12_cleaned.csv                # Cleaned LAMOST DR12 metadata
│   ├── mapping_result.csv                     # Mapping between obsid and targets
│   └── split_all/                             # Sharded FITS spectra
│       ├── all01/                              # Each shard directory contains FITS files
│       ├── all02/                              # all01–all10 contain 1,000,000 spectra each
│       ├── ...
│       └── all11/                              # 380,929 spectra
├── models/                                    # Pretrained or newly trained model weights
│   └── lgadnet_best.pth                       # Default model-weight filename for prediction
├── training/                                  # Training data generated by 00_train
│   ├── selected_samples.csv
│   ├── train_features.npy
│   ├── train_labels.csv
│   ├── val_features.npy
│   └── val_labels.csv
├── predictions/                               # Prediction outputs generated by 01_predict
│   ├── predictions_all.csv
│   └── cemp_all.csv
├── crossmatch/                                # Crossmatch files generated or used by 01_predict
│   ├── cemp_unique_b_greater_30.csv
│   ├── vizier_upload_with_id.csv
│   ├── vizier_crossmatch_result.csv            # Downloaded from VizieR and renamed manually
│   ├── vizier_dedup_double.csv
│   └── bailer_jones_distance_for_candidates.csv
├── screening/                                 # Screening outputs generated by 02_screen
│   ├── phase.csv
│   ├── candidates.csv
│   ├── egp.csv
│   ├── cmd_flags.csv
│   └── final.csv
├── catalog/                                    # Final release catalog generated by 04_catalog
│   └── mp_catalog.csv
└── figures/                                   # Figures and statistics generated by 03_plot
```

The training-data preparation script uses `mapping_result.csv` and the DR12 metadata to identify observations, then searches the shard directories under `split_all/` for the corresponding FITS spectra. Observations whose FITS files are not found are excluded from the training sample. The prediction script processes the selected shards under `split_all/`.

If you already have a trained model, you can skip training. Place its weights at `models/lgadnet_best.pth`. The training script writes best-model checkpoints with names such as `lgadnet_regression_<index>_best_model.pth`. Copy the checkpoint you want to use and rename it to `lgadnet_best.pth`, or pass its path explicitly with `--model-weight` during prediction.

## 2. Run the workflow in order

### 2.1 Training (optional)

To prepare a training dataset and train a model from scratch, run:

```bash
python scripts/00_train/01_prepare_training_dataset.py
python scripts/00_train/02_train_lgadnet.py
```

The first script generates `training/selected_samples.csv`, the training and validation label tables, and their feature arrays. The second trains the model from these files and writes model checkpoints and logs to `models/`. To regenerate training data when output files already exist, add `--overwrite` to the first command.

After training, select a best-model checkpoint in `models/` and copy or rename it to `lgadnet_best.pth` before running prediction.

### 2.2 Prediction and crossmatching

Predict all shards and merge the shard-level results:

```bash
python scripts/01_predict/01_predict_lgadnet_dr12.py --all-shards --merge --resume
```

The script writes shard-level results and the merged `predictions_all.csv` and `cemp_all.csv` to `predictions/`. Use `--resume` to continue an interrupted run.

Next, apply the spatial prefilter and prepare the VizieR upload table:

```bash
python scripts/01_predict/02_dedup_spatial_prefilter.py
python scripts/01_predict/03_prepare_vizier_upload.py
```

`03_prepare_vizier_upload.py` creates `crossmatch/vizier_upload_with_id.csv`. Upload this file to VizieR, crossmatch it with Gaia DR3, and download the result. **Rename the downloaded VizieR result to `vizier_crossmatch_result.csv` and place it in the `crossmatch/` directory**, then run:

```bash
python scripts/01_predict/04_dedup_vizier_double.py
python scripts/01_predict/05_query_bailer_jones_distance.py
```

The fourth script establishes a unique one-to-one match between candidates and Gaia sources and writes `vizier_dedup_double.csv`. The fifth queries Bailer–Jones distances online and writes `bailer_jones_distance_for_candidates.csv`. The VizieR crossmatch requires manual interaction and an internet connection; the distance query also requires an internet connection.

### 2.3 Phase-space, EGP, and CMD screening

The commands below write all screening products to `screening/`:

```bash
python scripts/02_screen/01_phase_space.py \
  --outdir "$LGADNET_ROOT/screening"

python scripts/02_screen/02_calculate_egp.py \
  --in-csv "$LGADNET_ROOT/screening/candidates.csv" \
  --outdir "$LGADNET_ROOT/screening"

python scripts/02_screen/03_cmd_screening.py \
  --in-csv "$LGADNET_ROOT/screening/egp.csv" \
  --outdir "$LGADNET_ROOT/screening"

python scripts/02_screen/04_export_cmd_retained_cemp.py \
  --in-csv "$LGADNET_ROOT/screening/cmd_flags.csv" \
  --outdir "$LGADNET_ROOT/screening"
```

In order, these commands generate `phase.csv` and `candidates.csv`, then `egp.csv` and `cmd_flags.csv`, and export the CMD-retained CEMP candidates to `final.csv`. The phase-space script reads `crossmatch/vizier_dedup_double.csv` and `crossmatch/bailer_jones_distance_for_candidates.csv`. The EGP script uses the spectral paths and redshifts in `crossmatch/cemp_unique_b_greater_30.csv`.

### 2.4 Build the release catalog

Build the full metal-poor catalog after prediction and screening:

```bash
python scripts/04_catalog/01_build_mp_catalog.py \
  --predictions "$LGADNET_ROOT/predictions/predictions_all.csv" \
  --outdir "$LGADNET_ROOT/catalog"
```

The script retains rows marked as metal-poor in `predictions_all.csv`, derives Galactic coordinates, and reads `DESIG` and `OBJNAME` from the source FITS headers referenced by `source_path`. Keep those FITS files accessible while building the catalog. Screening flags and phase-space quantities are added from the crossmatch and screening tables; the output is `catalog/mp_catalog.csv`.

### 2.5 Plotting

```bash
python scripts/03_plot/01_plot_cmd.py \
  --in-csv "$LGADNET_ROOT/screening/cmd_flags.csv" \
  --outdir "$LGADNET_ROOT/figures"

python scripts/03_plot/02_plot_density.py \
  --in-csv "$LGADNET_ROOT/screening/final.csv" \
  --outdir "$LGADNET_ROOT/figures"

python scripts/03_plot/03_plot_egp.py \
  --train-csv "$LGADNET_ROOT/training/train_labels_with_egp.csv" \
  --final-csv "$LGADNET_ROOT/screening/final.csv" \
  --outdir "$LGADNET_ROOT/figures"
```

The first two plots use `cmd_flags.csv` and `final.csv`, respectively. The EGP comparison plot also requires `training/train_labels_with_egp.csv` as a reference table for the training sample. The current training-data preparation script does not generate this file, so it must be prepared separately. If it is unavailable, skip the third plotting command.

## 3. Workflow and selection criteria

```text
00_train   → training-sample preparation and model training (optional)
01_predict → DR12 spectral prediction, candidate prefiltering, Gaia crossmatch, and distance query
02_screen  → phase-space screening, EGP calculation, CMD screening, and CMD-retained CEMP candidate export
03_plot    → figure generation
04_catalog → full metal-poor catalog construction
```

Selection criteria:
- Phase space: `Z = d·sin(b) + Zsun`, with `Zsun = 0.0208 kpc`; retain sources with `|Z| > 3 kpc` and `Vtan > 180 km/s`.
- EGP: `EGP = -2.5·log10(∫4200–4400 / ∫4425–4520)`.
- CMD: `(BP-RP)_0 ≥ 0.4` and `M_G ≤ 7.0`.

## 4. Script index

### 00_train
- `01_prepare_training_dataset.py`: generate training and validation data from metadata and FITS spectra.
- `02_train_lgadnet.py`: train the four-parameter regression model and save checkpoints.

### 01_predict
- `01_predict_lgadnet_dr12.py`: predict parameters and classify CEMP candidates by FITS shard.
- `02_dedup_spatial_prefilter.py`: deduplicate targets and apply the Galactic-latitude prefilter.
- `03_prepare_vizier_upload.py`: create the VizieR upload table.
- `04_dedup_vizier_double.py`: establish a unique match between candidates and Gaia sources.
- `05_query_bailer_jones_distance.py`: query Bailer–Jones distances.

### 02_screen
- `01_phase_space.py`: calculate phase-space quantities and apply the phase-space selection.
- `02_calculate_egp.py`: calculate EGP.
- `03_cmd_screening.py`: apply the CMD selection and write screening flags.
- `04_export_cmd_retained_cemp.py`: export CMD-retained CEMP candidates for downstream analysis and plots.

### 03_plot
- `01_plot_cmd.py`: plot the Gaia CMD.
- `02_plot_density.py`: plot parameter-space density.
- `03_plot_egp.py`: compare EGP distributions for training CEMP stars and CMD-retained CEMP candidates.

### 04_catalog
- `01_build_mp_catalog.py`: combine the full metal-poor prediction sample with screening flags and phase-space quantities.

## 5. Dependencies and citation

Use Python 3.12 or later. From the repository root, install the pinned dependencies with:

```bash
python -m pip install -r requirements.txt
```

`requirements.txt` records the package versions from the active Conda base environment. The PyTorch build may need to match the host's CUDA setup.

Paper: *LAMOST DR12 CEMP Candidate Search and Catalog Construction*. Please cite the corresponding paper when using this code.
